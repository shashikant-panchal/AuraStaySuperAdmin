# AuraStaySuperAdmin

**AuraStay Super Admin** is the centralized Multi-Tenant Hospitality SaaS Control Center.

## Features
- **SaaS Tenant Provisioning**: Register hotel properties, assign custom subdomains/slugs, brand logos, manager contact details, and initial room capacities.
- **Hotel Admin Credential Management**: Automatically generates and provisions secure login credentials for Hotel Admins to manage their individual PMS in AuraStay.
- **Cross-Property Inventory & Booking Monitor**: Real-time unified analytics for global reservations, gross platform revenue, and live room states.
- **Real-Time Supabase Synchronization**: Backed by PostgreSQL with Row Level Security (RLS) and WebSocket publication for instant cross-tier updates.

## Tech Stack
- React 18 + Vite
- Tailwind CSS
- Lucide React
- Supabase Realtime Client
